## Getting Started

1. **Clone the repository:**
    ```bash
    git clone git@github.com:Landstede-Racing/landstede-racing.git
    ```
2. **Open in Unity:**
    - Use Unity Hub to add the project folder.
    - Open with Unity 6000.2.10f1
